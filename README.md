# 学习任务表

一个简单的学习任务管理网页应用。

## 文件说明

| 文件 | 说明 |
|------|------|
| index.html | 主页，显示任务列表 |
| add.html | 新增/编辑任务页面 |
| style.css | 样式文件 |
| javascript.js | 主页逻辑 |

## 功能

- 显示学习任务列表
- 新增任务
- 编辑任务
- 删除任务
- 数据保存在浏览器 localStorage 中

## 使用方法

1. 用浏览器打开 `index.html`
2. 点击"新增任务"按钮添加任务
3. 在列表中点击"编辑"或"删除"操作任务

## 数据结构

每条任务包含以下字段：

| 字段 | 说明 | 是否必填 |
|------|------|----------|
| name | 学习任务名称 | 是 |
| startDate | 开始时间 | 否 |
| endDate | 结束时间 | 否 |
| remaining | 剩余天数 | 否 |
| progress | 完成度 | 否 |
| content | 学习内容 | 否 |

## 技术栈

- HTML
- CSS
- JavaScript（原生）
- localStorage（本地存储）
